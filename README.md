## 🎯 Background & The Problem

In academic environments, Turnitin Similarity Reports and AI Writing Reports are standard benchmarks for originality. However, with the rise of forged reports, edited PDF overlays, and manipulated metadata generated by third-party paper mills or malicious actors, **distinguishing authentic Turnitin certificates from counterfeits has become increasingly difficult**.

Common forgery tactics include:
- Modifying similarity percentages or AI writing scores using PDF editors (Adobe Acrobat, Preview, etc.).
- Stitching genuine header pages with altered body text.
- Fabricating submission dates to mask missed deadlines.
- Generating fake "Official Turnitin Digital Receipts" with invalid Submission ID formats.

**Turnitin Report Forensics** provides an instant, automated forensic screening suite that extracts internal PDF structures and audits chronological consistency—**without ever uploading the document to any server**.

## ✨ Key Features

- **🛡️ 100% Client-Side & Zero-Upload**: All parsing and binary analysis happens within your local browser runtime. Sensitive student manuscripts and institutional records never leave your machine.
- **⏱️ Chronological Timeline Audit**: Compares `CreationDate`, `ModDate`, `Submission Time`, and receipt timestamps to identify retroactive tampering.
- **🧬 PDF Producer & Font Forensics**: Checks internal PDF Producers (`iText`, `Apache FOP`, `Skia/PDF`, etc.) against legitimate Turnitin rendering engines. Flags external editing footprints like Adobe Illustrator or Acrobat Distiller.
- **🆔 Submission ID Format & Range Check**: Cross-references 9-to-10 digit Turnitin submission ID patterns against known temporal range benchmarks.
- **📊 Multi-File Batch Comparison**: Drop multiple versions of a report to immediately contrast page-count shifts, word-count variances, and metadata drift.
- **🌐 Bilingual UI**: Seamless one-click toggle between English and Simplified Chinese (简体中文).

## 🔬 Forensic Verification Checklist

| Forensic Vector | Expected Official Indicator | Anomaly / Suspicious Footprint |
| :--- | :--- | :--- |
| **PDF Producer** | Authentic Turnitin conversion pipelines | `Adobe Acrobat Pro`, `macOS Quartz`, `Canva`, `Microsoft Word` |
| **Timeline Integrity** | `CreationDate ≈ ModDate ≈ Submission Date` | `ModDate` significantly later than `CreationDate` |
| **Object Hierarchy** | Monolithic linear stream structure | Incremental update trailers (`%EOF` appended multiple times) |
| **Submission ID** | Monotonically aligned with chronological era | Truncated digits, non-numeric noise, or historical range mismatch |
| **Font Embedding** | Standard subsetted Turnitin typography | Injected system fonts or mismatched glyph mappings |

## 🔒 Privacy & Security Model

> **Academic integrity investigations require strict student confidentiality.**

1. **No Backend**: There is no Node.js, Python, or API server processing your files.
2. **Local ArrayBuffer Parsing**: The PDF binary is read using native browser `FileReader` API as an `ArrayBuffer` directly in client memory.
3. **No External CDN Tracking**: No cookies, no session tracking, and no telemetry data collection.
